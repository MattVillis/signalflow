2026-10-08

  • VLAN lists in and out. The VLAN registry has Import…, Export and CSV. Hand a house VLAN plan to another crew as a file, or bring one in from the network person's spreadsheet: VLAN, NAME, SUBNET, FROM, COLOUR, with or without a header row. Import only adds: a VLAN number you already have is left exactly as it is.
  • Back to the library version. A device whose ports you edited by hand has a ↺ Library version button in its editor. It puts the ports and width back to the library symbol and keeps the VLAN, trunk, LAG and IP settings on its ports. It warns you if a port only that device had (and any cable on it) will go.
  • Replace several devices at once. Select them all (eight encoders, say) and press R or Replace…. Every device is worked out on its own and the list ranks symbols by how many cables they keep across the lot. A table shows any device that would lose a cable or a VLAN setting. One Ctrl+Z undoes the whole swap.
  • New VLANs get their own colours. VLANs numbered 10, 20, 30… all came out the same blue. Each VLAN you add now takes a colour no other VLAN is using. If an existing project already has several on one colour, the registry offers a button to give each its own.
  • Numbered ports can start anywhere. Add multiple has a from box: set 25 to add PORT 25–26 for the 1G pair on a 24+2 switch. Leave it blank to carry on from the last number as before.
  • Cable numbers stay put. A cable keeps its number for good, so labels you have already printed stay right: a new cable takes the next free number instead of shifting everything after it, and deleting one leaves a gap rather than renumbering the rest. Older projects are numbered on open exactly as their lists printed before. Breakout legs still share their DAC's number. Renumber… in Lists → Cables starts again from C001 when you want a clean set. A selected cable shows its number, and Ctrl+F finds a cable by the label in your hand (C13, C013-2).
  • Only the left button moves things. Middle-drag now pans the sheet even when it starts on a symbol, and a right-click no longer drags a symbol, note or cable end around.
  • 40G breakouts into SFP28 ports. A QSFP+ 4× 10G breakout DAC can now land its tails in SFP28 ports as well as SFP+ ones — even a mix on the same cable. Those legs carry the note *SFP+ leg in SFP28 port · runs at 10G*.
  • QSFP+ into a QSFP28 port is allowed. A 100G QSFP28 port takes a 40G QSFP+ module, so that cable now links with the note *QSFP+ module in QSFP28 port · runs at 40G*, the same way SFP+ into SFP28 does.
  • Shortcuts work on every keyboard layout. On Russian, Greek, Hebrew and other non-Latin layouts the letter shortcuts did nothing — Ctrl+Z and Ctrl+S included — and now work from the same keys. On French (AZERTY) keyboards the number shortcuts work without Shift: hold 1 / 2 / 3 while clicking a port, and 0 to reset the zoom. Letter shortcuts still follow the letter printed on your key, so Ctrl+Z is the key labelled Z, as in every other app.
  • Replacing a switch keeps the VLANs on unpatched ports too. Ports you had set up with a VLAN, trunk, LAG or IP before anything was plugged in now move to the new switch as well — same port name where it exists, otherwise the next free port. They are listed in the Replace table under the cables, can be moved by hand, and if the new switch has no room for some of them the window says so before you commit.
  • Pressing R no longer types an "r" into the Replace search. The window opens with an empty search box, ready to type.
  • SFP+ into an SFP28 port is allowed. A 25G SFP28 port takes a 10G SFP+ module, so that cable now links instead of being refused, with the note *SFP+ module in SFP28 port · runs at 10G* in the popover and the cable list.
  • Replace a symbol and keep its cables. Select a device and press R (or Replace… in the toolbar, or in the device editor) to swap it for a different symbol — a 48-port switch for a 16-port one, a Videohub 40x40 for a 20x20. Each cable moves to a matching port on the new symbol: same name first, then the same kind of port in order, so cables on ports 40 and 41 land on the next free ports rather than anywhere. The list shows up front whether each symbol fits all your cables, fits only with adapters, or drops some, and a table shows where every cable will go — change any of them by hand. If a cable has nowhere to go, it says so in red before you commit, and Ctrl+Z brings everything back. The device keeps its name and IP, and each port's VLAN, trunk and LAG settings move with its cable.
  • Choose where your project is saved. Save now asks where to put the file and what to call it, instead of dropping it in Downloads. After that the project remembers its file: the next Save (Ctrl+S) asks whether to overwrite it or save as a new file — press Enter to overwrite. Save as (Ctrl+Shift+S) always asks for a new location. Opening a project links it to that file too, and the status bar shows which file you are working on. Works in Chrome and Edge; Firefox and Safari still download a copy, as before.
  • Windows no longer close when a drag ends outside them. Selecting text in a field and letting go past the edge of the window used to count as a click on the background, closing it and losing whatever you had typed. A window now closes only on a real click outside it, or its close button.

2026-10-05

  • Big cable bundles no longer freeze the sheet. A drawing with a large run of cables between two columns (70+ off a router into a row of servers) could lock the page for many seconds on every move, drag or edit while the cable spacing was worked out again from scratch. The spacing is now worked out much faster, remembered for the parts of the sheet you did not touch, and held still while you drag, then settled once you let go. The cables are drawn in exactly the same places as before.
  • Fibre ports take VLANs too. An SFP or fibre port now has the same VLAN, ACCESS / TRUNK, tagged-VLAN, LAG and IP fields as a copper network port, so a switch's fibre uplinks and a server's SFP NIC can be set up properly. A fibre cable on an access VLAN is drawn in that VLAN's colour and stays solid, so you can still tell it from copper. It also counts in the VLAN registry, the cable list, auto-IP and the switch config output.
  • Switch change sets for NETGEAR M4250 / GSM. Lists gained a SWITCH CONFIG tab: pick a switch and it writes the commands for the things the drawing is actually sure about — VLANs and their names, port PVIDs, trunk tagging, LAG membership and the management address — ready to review and paste. Two syntaxes: NETGEAR's classic vlan participation / vlan pvid / vlan tagging, or the shorter switchport form. Copy it, or download one .txt per switch.
  • It is a change set, not a config. It never writes spanning tree, QoS, IGMP snooping, PoE or anything else it cannot read off the sheet, and it deletes nothing — the one removal, taking access ports out of VLAN 1, is a tick-box that is off until you ask. It never saves on the switch either: apply, verify, then write memory yourself, so a reboot undoes a mistake.
  • It prints the port map first. Every interface it is about to touch, with the port label it came from and what it will do — because an off-by-one between PORT 1 and 1/0/1 is an outage, and that is the one thing worth checking by eye. If a switch numbers its ports differently, give it a pattern in the device editor (1/0/{n}, xe-0/0/{n}) and everything follows.
  • It warns you about the cable you are sitting on. If the switch has a management address, the change set names the port carrying that VLAN and tells you to do that one from the console — re-PVIDing it from a session that runs through it cuts you off mid-paste.
  • Leader LT4670 sync generator, with its option modules. The chassis carries the genlock loop, six analog black outputs, CW/1PPS, word clock, silence, AES/EBU, LTC/remote, L-SYNC and the ethernet port; the five hardware options are slots you fill in the device editor — SER01 GNSS, SER02 3G-SDI (two can be fitted, so there are two positions), SER03 PTP SFPs, SER04 25G-IP plus 12G-SDI, and SER11 redundant power. It is placed with the GNSS and the first SDI pair fitted; add the rest from MODULES. SER02 and SER04 cannot be fitted together in the real instrument, which the card names say — the drawing cannot stop you.
  • Three connectors the catalogue was missing: HD-BNC (micro-BNC, on 12G gear), DIN 1.0/2.3 (word clock and AES/EBU on sync panels) and D-SUB 15 / D-SUB 26. The miniature 1.0/2.3 series is not a BNC, so patching one to a full-size BNC is allowed and the cable list asks for the adapter lead.
  • Slot headers stop printing through each other. On a chassis with an input card down one side and an output card down the other, the two slot headings landed on the same line and overlapped. Each now takes its own row.

2026-10-04

  • The whole Dante AVIO range. All eight Audinate adapters are in the library under Audio: analog in 1 and 2 channel, analog out 1 and 2 channel, the AES3 2x2, the USB and USB-C adapters, and the Bluetooth 2x1. Connector genders are on the ports where you need them — IN 1 XLR-F, OUT 2 XLR-M — because that is what decides which cable you pack. None of them has a mains inlet, which is right: every AVIO runs on PoE from the switch, and the Dante port says so, so an Alt+6 power view lights the adapters fed over their network cable.
  • An SFP cage can be patched with copper. A cage is a hole — what comes out of it is whatever module you put in — so an SFP+ or SFP port now links to an RJ45 10G, RJ45 or etherCON port instead of being refused. It was asked for on the Matrox Avio 2 TX and RX, whose two media cages take 1GbE or 10GbE fibre or copper, and it applies to every cage in the library. The link names the module it needs — NEEDS 10GBASE-T SFP+ MODULE + CAT6A — in the popover and in the cable list, so it gets ordered, and because the cable in your hand is Cat6a the run draws, filters and legends as network rather than fibre.
  • The legend and the title block fold away. Both sit in the corners of the window rather than on the paper, so on a laptop they covered the drawing. Each has a ▾ now and folds to a small chip you click to bring it back; the choice is remembered. Both are still drawn on every export, folded or not.
  • Esc closes one thing at a time. It used to clear everything at once — a stray Esc aimed at a menu also dropped the ghost view you were working in and your selection. It now closes the topmost thing: dialog, then popover, then the tool or half-drawn cable, then the ghost filter, then the selection. Opening a dialog also closes whatever popover was open, instead of stacking on top of it.
  • Keyboard shortcuts are grouped. The ? panel is now Draw / Link / Edit / View / Ghost sheets / File instead of one long list, and it fits a laptop screen — as does the toolbar, which wraps rather than running off the edge.
  • Print / PDF is no longer greyed out. It picks A3 for you if you have not chosen a paper size, and says so, rather than sitting there looking broken.
  • The AI builder asks two clear questions. *What you have* — a rear-panel drawing, or a model number. *Who does the work* — the local bridge, the Claude API, or any agent you already use. The help text and the fields now follow the engine you picked, instead of describing one while another was selected.
  • Labels on the things that had none. Column headings (gap, label, side, direction, signal, connector) over every port editor; a WIDTH label on the width box; LIB on the two library file buttons in the sidebar, which read as Save and Open; synced 14:44 instead of ✓ 14:44; distinct icons for bring to front and send to back, which looked like import and export; and tooltips that say why a button is greyed out instead of nothing at all.
  • Fibre, not fiber. The legend now matches the rest of the app's spelling.
  • Switch ports can be trunks, carry several VLANs, and join a LAG. The VLAN row in the device editor gained an ACCESS / TRUNK button, a LAG box and — on a trunk — a row of VLAN chips for everything it carries tagged. The single VLAN dropdown becomes the native VLAN once a port is a trunk.
  • The drawing says so. A trunk or LAG port carries a small line under its label — TRUNK 10,20 · LAG UP1 — beside the address line. A trunk is no longer coloured as though it were one VLAN: the port text and its cable stay plain network, because a trunk is not a single service.
  • Patch sheet and cable list follow. SWITCH PORTS gained MODE (ACCESS / TRUNK) and LAG columns, and its VLAN cell now reads the whole story — 10, TRUNK 20,30, or 1 + TAG 10,20. The cable list names the trunk and notes LAG membership. Both reach CSV and the printable sheet.
  • The VLAN registry shows what each VLAN is doing. Every row now carries a use count — 2A 4T, two untagged ports and four tagged on a trunk — so you can see what a VLAN is carrying, and what deleting it would strand. Hover for the detail.
  • Flags always name the port. An off-page or same-sheet flag used to be cut at 24 characters, which on a long device name ate the port entirely — the one thing the flag exists to tell you. The port is now reserved first and the device name shortened to fit, model end first, so LIGHTWARE MX2-48x48-DH-48DPio-A-R reads MX2-48x48-DH-48… · DP IN 1 and DISGUISE VX 4+ reads VX 4+ · ETH D 100G. Hover any flag for the full name, sheet and port.
  • Breakout DACs. A 100G QSFP28 port can now be cabled to up to four 25G (SFP28) or 10G (SFP+) ports, and a 40G QSFP+ to four 10G — the one place the drawing allows more than one cable on a port, because it really is one cable. Click the trunk once and it stays armed: each following port click lands the next lane, and the toast counts you through lane 2 of 4. A fifth is refused.
  • One DAC, not four patch leads. Each leg is tagged DAC 2/4 on the sheet where it lands, and in the cable list the legs share one number with a lane suffix — C012-1 … C012-4 — and name the assembly, so the order is for one breakout cable. The switch patch sheet gives a trunk port a row per lane.
  • A port you just cabled is clickable again. Clicking the end dot of a selected cable used to do nothing, which made the port look dead the moment a cable landed on it. A click with no drag now goes through to the port; dragging still re-patches the end.
  • Auto-IP skips trunk ports. A trunk carries many subnets, so it is no basis for handing the device at the far end an address.

2026-10-02

  • Earlier versions stay up. Every release now lives at its own address, listed at [versions](https://mattvillis.github.io/signalflow/versions.html) and linked from What's new. If a new version misbehaves, open the one before it and carry on — your projects are files on your machine and open in any version. Each release also carries a downloadable standalone on GitHub.
  • Link… can target exact ports. Each device in the Link… dialog now has an All ports button: open it and tick precisely which ports take part. They pair in the order shown, so ticking OUT 5-8 on the source and IN 1-4 on the destination wires 5→1, 6→2, 7→3, 8→4 in one go. Leave it alone and nothing changes — every matching port is used, exactly as before.
  • Fixed: moving the print box reset the size you had dragged it to, so it jumped back to one sheet at 100%. It now keeps its size wherever you put it.
  • Drag the print box to choose what goes on the paper. Pick a page size and the dashed frame on the sheet grows corner handles: drag it around whatever you want printed and the frame tab tells you the scale as you go (A4 · 297 × 210 · 70%). The paper never changes size — the drawing is fitted to it — so a whole stage goes on one A3 and a single rack goes on A4 at full size. FIT BOX in the Export menu sizes the frame around everything in one click. The legend and title block keep their printed size however far you zoom out, so they stay legible.
  • Link… can target exact ports. Each device in the Link… dialog now has an All ports button: open it and tick precisely which ports take part. They pair in the order shown, so ticking OUT 5-8 on the source and IN 1-4 on the destination wires 5→1, 6→2, 7→3, 8→4 in one go. Leave it alone and nothing changes — every matching port is used, exactly as before.
  • Scale to fit the paper. Pick a page size in the Export menu and there is now a FIT toggle beside it: the drawing is scaled to fit the sheet while the paper stays exactly the size you chose, so a big stage still prints on one A3. The menu tells you what it will do ("scaled to fit — 51% on A4") before you commit, and the legend and title block keep their own size so they stay legible at any scale. Applies to the SVG, Print and PDF alike.
  • One hop over a whole bundle. With ARC crossings selected, a run that crosses several cables close together now leaves the line once, arcs over the lot and lands the other side, instead of a row of little bumps. A lone crossing is unchanged. Wide bundles give a long shallow arc rather than a balloon, and GAP behaves the same way — one break, not several.
  • SignalFlow 1.0 — out of beta. This is the first full release. From here on releases carry plain version numbers: a patch (1.0.1) fixes bugs, a minor version (1.1) adds features, and a major version (2.0) would only come with a change to the project file format. Settings and the logo tooltip show the version you are running next to the build stamp; quote it in bug reports.
  • Links that open straight onto a screen. Add ?show=vlan, ?show=lists:switches, ?show=export, ?show=ai:research or ?show=settings to the app's address and it opens there; ?focus=network,video starts in a ghost view and ?q=videohub pre-fills the library search. Handy for pointing a colleague at exactly the thing you mean.
  • An example project to explore. ?open=examples/avoip-stage.signalflow.json loads an AV-over-IP stage: encoders and decoders on a switch with CONTROL, AV and DANTE VLANs, IPs already assigned and a full switch patch sheet. A tab opened from one of these links does not auto-save, so it never replaces the session you left last time. Use Save if you want to keep your changes.

2026-09-30

  • A tidy-up pass on the small stuff. The collapse chip in a symbol header now sits on the header's centre line instead of hugging the top border, and the edited dot mirrors it on the right. In the Export menu the SIGNAL and PAGE rows line up, and a wrapped second row of signals sits under the first chip rather than under the label. Settings checkboxes are the app's own teal instead of browser blue. The sidebar's New symbol button is centred like the AI builder above it. In the device editor the IP row lines up with the port name above it. The legend's hop buttons no longer change size when you pick one, and the equipment list shows categories in caps like every other column.

2026-09-29

  • Power connects whatever the two ends are, and the cable list says which lead. A C13 outlet into a C14 inlet, a distro into a TRUE1 server, a DC brick — none of it is refused any more, because the lead always exists. What matters is which one, so the NOTE column specs it: IEC C13-C14 JUMPER, IEC C13 TO TRUE1 LEAD, PSU / ADAPTER · IEC C13 TO DC. Direction still applies — two inlets cannot feed each other — and Link… now treats every power port as one group, so a rack of mixed connectors cables in one go.
  • Link… can cable power. Select a distro and the gear it feeds, and the connector list now offers IEC MAINS, wiring each free outlet to the next free inlet. It never appeared before because a distro outlet is IEC C13 and a device inlet is C14: two unrelated connectors as far as the planner was concerned, so neither had both an output and an input to pair. Cables whose ends differ are now grouped by family, which also fixes RJ45 to etherCON, USB A-to-B and mixing 12G with 3G SDI in the same run.
  • Ctrl+Alt shortcuts no longer double up. Ctrl+Alt+V was toggling the video ghost *and* pasting the clipboard; the same overlap hit Ctrl+Alt+F (fit), Ctrl+Alt+N (note tool), Ctrl+Alt+C (collapse) and Ctrl+Alt+A (select all). The ghost mnemonics are now their own thing, and the ordinary Ctrl and bare-key shortcuts ignore anything held with Alt.
  • Ghosted kit is properly out of the way. Dragging a marquee, or Ctrl+A, no longer picks up equipment the ghost filter has faded. If you cannot see it you cannot select it, so it cannot be moved or deleted by accident either.
  • USB never blocks on direction. A USB socket is a socket: two ports that both read IN will still take a lead between them. The arrows stay on the drawing where they mean something — which way video or power flows on a USB-C port, or NovaStar cascade order — they just no longer stop you cabling. While checking that: NovaStar cascade USB IN is a Type-B socket and USB OUT is Type-A, per the VX1000 spec, so the VX1000, VX600 and MCTRL4K now say so.
  • USB cables just work. USB-A, USB-B and USB-C now connect to each other — an A-to-B or A-to-C lead is an ordinary cable, not a converter, and the app was wrongly asking for one. USB-B is a connector type in its own right now, so the ports that really are type B — the Taurus UCX host ports, the VINX service port — are drawn and listed as USB-B, and the cable list names both ends so the right lead gets ordered. USB-C into an HDMI or DisplayPort input is allowed too, flagged as needing that cable. Thanks to the beta user who reported it.

2026-09-28

  • What's new, in the app. This panel. The status bar carries a dot until the newest entry has been read, and the full history is a page on the site.
  • Ghost sheets. Alt+1 … Alt+6 — or Ctrl+Alt+V/F/N/A/C/P — fades everything that is not carrying that signal, so a busy sheet becomes just the network, or just the video. They stack, Esc clears, and alt-clicking a legend row does the same. A chip top-left names the filter.
  • It follows the signal through the kit. A fibre run is never a service of its own, so it carries whatever the box at its end terminates: focusing VIDEO keeps the fibre between a TX and an RX, focusing NETWORK keeps a fibre trunk carrying the LAN. An RJ45 is read off its port name — AV, TPS, TPX, SDVoE and NDI ports are an AV stream, DANTE is audio, plain LAN stays the network — so an AV-over-IP chain shows encoder, switch and decoder without the rest of the LAN lighting up. PoE counts as power.
  • Export and save by signal. The Export menu has a SIGNAL row: tick what you want and it drives the SVG, the Print/PDF and a new project copy holding only those cables and the equipment they touch. A normal Save now remembers the view you were in, without removing anything from the file.
  • Lightware, in full — 52 symbols. MX2 matrices including the audio and redundant frames and the DH DisplayPort hybrids, Taurus UCX across its generations, MMX multiport switchers, TPS / TPX / OPTX extenders, VINX, Gemini GVN and UBEX. Ports come from Lightware's own per-model port diagrams.
  • openGear frames. Ross OGX-FR and AJA OG-X-FR with an 18-card catalogue from AJA, Cobalt Digital and Ross. Cards are listed as card + rear-module pairings, because in openGear the rear module is what decides the connectors.
  • Power everywhere. Every symbol that takes mains now has an inlet, DC and 4-pin XLR are proper connector types, and the demo sheet ships with a 12-way distro cabled to everything. One fix worth naming: the disguise EX 3 was drawn with dual IEC — the whole VX/GX/EX range is a single powerCON TRUE1.

2026-09-25

  • VLAN subnets and automatic IPs. Give a VLAN a subnet and, with the setting on, anything you patch to it gets the next free address — shown under the symbol name, or under the port itself when a box has several LAN connections. Switches are skipped, and the VLAN is taken from either end of the cable.
  • Your VLAN scheme persists. "Save as defaults" keeps your numbering for every new project, and it travels inside the library file between machines.
  • Switch patch sheet. A third call list: every network port on every switch, its VLAN, what it connects to and the cable number. Spare ports are listed too, so it doubles as a free-capacity check.
  • KVM category with the ADDERLink XDIP and Matrox Avio 2, transmitter and receiver each.
  • Tidier library footer — the file actions became icons and the Repo button now carries its own sync status.
